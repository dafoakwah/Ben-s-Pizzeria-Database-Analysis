# Ben's Pizzeria - Order & Inventory Management 🍕📊

This project is a database dashboard for **Ben's Pizzeria**, designed to track **order activity** and **inventory management** efficiently. The dashboard currently displays key SQL queries and database insights, with plans to add data visualizations in the future. 

## 📌 Features

### **Dashboard 1: Order Activity**
Tracks real-time order details, including:
- 📦 **Total Orders**
- 💰 **Total Sales**
- 📊 **Total Items Sold**
- 📉 **Average Order Value**
- 🏷️ **Sales by Category**
- 🔥 **Top-Selling Items**
- ⏰ **Orders & Sales by Hour**
- 🏠 **Orders by Address**
- 🚚 **Orders by Delivery/Pickup**

### **Dashboard 2: Inventory Management**
Monitors ingredient usage and stock levels:
- 📦 **Total Quantity by Ingredient**
- 💰 **Total Cost of Ingredients**
- 🍕 **Calculated Cost of Pizza**
- 📉 **Stock Remaining by Ingredient**

## 📄 SQL Queries Used
The project uses SQL queries to extract and analyze data from the **pizzeria database**, including:
- Order details query
- Stock calculations (`stock1` view)
- Inventory remaining query
- Staff cost calculation  

_All queries are included in the HTML file for reference._
